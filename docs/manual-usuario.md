# Manual de usuario del portal de indicadores de proveedores HACEB

## 1. Introducción al sistema
El proyecto EstudIA | Automatización de Indicadores HACEB tiene como propósito desarrollar una solución que facilite la consulta de indicadores mensuales por parte de los proveedores nacionales.

Actualmente, el reto identificado consiste en reducir el trabajo manual asociado al envío mensual de indicadores a los proveedores. Como parte de la solución propuesta, se contempla un portal que permita consultar los indicadores publicados, de acuerdo con el rol de cada usuario.

**Estado del documento:** las instrucciones relacionadas con funcionalidades y pantallas que todavía no han sido verificadas se identificarán como pendientes de validación.

## 2. Objetivo del portal

Orientar a los usuarios en el uso del portal de consulta de indicadores de proveedores HACEB, mediante instrucciones sencillas para acceder al sistema, consultar la información disponible y, cuando corresponda, realizar las tareas administrativas autorizadas.

Este manual se ajustará al alcance funcional aprobado y se actualizará a medida que las funcionalidades estén disponibles y puedan verificarse.

## 3. Tipos de usuarios

El portal contempla dos roles de usuario: PROVEEDOR y ADMIN. Cada rol tiene permisos y funcionalidades diferentes, de acuerdo con las responsabilidades asignadas.

### 3.1. Usuario PROVEEDOR

El proveedor podrá consultar los indicadores que hayan sido publicados y que correspondan a su proveedor, de acuerdo con el diseño funcional del proyecto.

Las funcionalidades previstas son:

- Consultar los indicadores publicados que le correspondan.
- Seleccionar un período mensual para consultar la información disponible.
- Consultar períodos anteriores cuando exista información publicada para ellos.

**Estado:** funcionalidades pendientes de validación en el portal. La disponibilidad de cada opción deberá comprobarse cuando el módulo esté habilitado.

**Captura de pantalla:** pendiente hasta que el módulo del proveedor esté disponible.

### 3.2. Usuario ADMIN

El administrador tendrá responsabilidades relacionadas con la gestión de proveedores y las publicaciones de indicadores, según el alcance definido para el proyecto.

Las funcionalidades previstas son:

- Consultar la información de los proveedores registrados.
- Gestionar las publicaciones mensuales de indicadores.

**Estado:** funcionalidades pendientes de validación con Valentina (FE-02) y de comprobación en el portal.

**Captura de pantalla:** pendiente hasta que el módulo administrativo esté disponible.

## 5. Consulta de indicadores para proveedores

Esta sección describe el procedimiento previsto para que un usuario con rol PROVEEDOR consulte sus indicadores mensuales publicados.

### 5.1. Selección del período mensual

El proveedor podrá seleccionar un período mensual para consultar los indicadores disponibles, de acuerdo con las funcionalidades previstas en el proyecto.

**Procedimiento previsto:**

1. Iniciar sesión con una cuenta autorizada para el rol PROVEEDOR.
2. Ingresar al módulo de consulta de indicadores, cuando esté disponible.
3. Identificar el control destinado a seleccionar el período mensual.
4. Seleccionar el mes y el año que se desea consultar.
5. Consultar la información disponible para el período seleccionado.

**Estado:** pendiente de validación. Deben comprobarse el nombre del módulo, el control de selección y los pasos reales en el portal.

**Captura de pantalla:** pendiente.

### 5.2. Consulta de indicadores publicados

El portal está diseñado para que el proveedor consulte los indicadores publicados que le correspondan, sin acceder a la información de otros proveedores.

**Procedimiento previsto:**

1. Iniciar sesión con el rol PROVEEDOR.
2. Seleccionar el período mensual que se desea consultar.
3. Revisar los indicadores publicados que correspondan al proveedor.
4. Confirmar que la información mostrada corresponda al período seleccionado.

La información disponible dependerá de las publicaciones existentes y de los permisos asignados al usuario.

**Estado:** pendiente de validación en el portal.

**Captura de pantalla:** pendiente.

### 5.3. Consulta de períodos anteriores

El diseño del proyecto contempla la consulta de indicadores de períodos anteriores cuando exista información publicada.

**Procedimiento previsto:**

1. Acceder al módulo de consulta.
2. Seleccionar un período anterior.
3. Revisar si existen indicadores publicados para ese período.

**Estado:** pendiente de comprobar que esta opción esté disponible y verificar su funcionamiento.

**Captura de pantalla:** pendiente.

## 7. Mensajes y errores frecuentes

Esta sección describe situaciones que pueden presentarse durante el uso del portal. Los mensajes exactos deberán comprobarse cuando el sistema esté disponible para realizar pruebas.

### 7.1. No existen indicadores disponibles

Cuando el proveedor seleccione un período mensual sin indicadores publicados, el portal debería informar que no hay información disponible para ese período.

**Mensaje esperado, pendiente de validación:** «No hay indicadores disponibles para el período seleccionado».

**Procedimiento recomendado:**

1. Verificar que se haya seleccionado el mes y el año correctos.
2. Comprobar si existen indicadores publicados para el período seleccionado.
3. Si el mensaje continúa apareciendo y se esperaba encontrar información, comunicar la situación al equipo responsable.

**Estado:** pendiente de comprobar el mensaje real y el comportamiento del portal.

### 7.2. Problemas para iniciar sesión

Si el usuario no consigue acceder al portal, deberá verificar que está utilizando las credenciales autorizadas.

**Procedimiento recomendado:**

1. Comprobar que los datos de acceso se hayan escrito correctamente.
2. Intentar nuevamente el acceso.
3. Si el problema continúa, informar al equipo responsable para recibir orientación.

**Estado:** pendiente de validar los mensajes y las opciones de recuperación de acceso disponibles.

### 7.3. Información no disponible o problemas de consulta

Si no se visualizan los indicadores esperados, se recomienda verificar el período seleccionado y confirmar que existan publicaciones para ese mes.

Si la situación continúa, deberá informarse al equipo responsable para que revise el caso.

**Estado:** pendiente de validación en el portal.

**Capturas de pantalla:** pendientes hasta disponer de las pantallas y mensajes reales.

## 8. Cierre de sesión

El cierre de sesión permite que el usuario termine su acceso al portal de forma segura.

### 8.1. Procedimiento de cierre de sesión

1. Identificar la opción de cierre de sesión en el portal, cuando esté disponible.
2. Seleccionar dicha opción.
3. Verificar que el sistema finalice la sesión y que ya no permita acceder a las funcionalidades protegidas sin volver a iniciar sesión.

**Recomendación de seguridad:** cerrar la sesión al terminar de utilizar el portal, especialmente cuando se accede desde un equipo compartido.

**Estado:** pendiente de validación. Se debe comprobar la ubicación de la opción de cierre de sesión y el comportamiento real del sistema.

**Captura de pantalla:** pendiente hasta que la pantalla esté disponible.
