# automatizacion-indicadores-proveedores
Automatización del envío mensual de indicadores a proveedores nacionales - Reto EstudIA / Industrias Haceb
## Descripción del proyecto

Proyecto desarrollado en el programa EstudIA,
basado en un reto empresarial de Industrias Haceb.

## Objetivo

Diseñar e implementar una solución para automatizar
el envío mensual de indicadores a proveedores
nacionales, reduciendo tareas manuales y errores.

## Metodología de trabajo

- Desarrollo colaborativo mediante GitHub.
- Uso de ramas para cada funcionalidad.
- Integración de cambios mediante Pull Requests.
- Revisión de código entre compañeros.
- Uso de tecnologías open source.

## Estado del proyecto

Fase inicial: análisis de requerimientos y
definición de la solución.
